# Папка `comic_pages`

## Назначение

Эта папка зарезервирована под **постраничные изображения обучающего комикса** —
например, `page-1.jpg`, `page-2.jpg`, … `page-6.jpg`. Изображения служат
**резервным (fallback) источником** отображения комикса на странице `медиа.html`.

## Основной механизм отображения комикса

Основной способ показа комикса — это **pdf.js**, который рендерит файл
`Комикс.pdf` (лежит в корне проекта) в слайдере на странице `медиа.html`.
Этот механизм является основным и сохраняется без изменений.

Резервные изображения из папки `comic_pages` могут быть задействованы только
в том случае, если **pdf.js или `Комикс.pdf` недоступны** — например, при
локальном открытии сайта через протокол `file://`, когда браузер блокирует
загрузку PDF из-за политики доступа к файлам, либо при недоступности CDN с
библиотекой pdf.js.

## Рекомендованный формат именования файлов

Файлы изображений именуются по номеру страницы комикса:

- `page-1.jpg`
- `page-2.jpg`
- `page-3.jpg`
- … и так далее по порядку страниц.

То есть шаблон именования — `page-N.jpg`, где `N` — номер страницы.

## Текущее состояние

На момент написания этого описания папка **пуста**, и резервный механизм
отображения комикса **не активирован**.

Точка расширения для резервного сценария обозначена в JS-коде страницы
`медиа.html` — рядом с обработчиком `.catch(...)` у вызова pdf.js
(`pdfjsLib.getDocument(...)`). Именно туда при необходимости можно добавить
вывод последовательности `<img src="comic_pages/page-N.jpg">` вместо текстовой
заглушки. Чтобы активировать резервный показ, достаточно положить в эту папку
постраничные изображения с указанными выше именами и дополнить обработчик
`.catch(...)`.
